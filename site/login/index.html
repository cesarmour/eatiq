Como montar o atalho (5 minutos, uma vez)

          
App Atalhos › + › adicione as ações na ordem. Depois, em Automação, agende para rodar todo dia às 6h.

          
    
            
  1. Data › "Ontem".
    2. 
            
  2. Buscar amostras de saúde: tipo Passos, data de início = Ontem. Depois Calcular estatísticas › Soma. Nomeie a variável passos.
    3. 
            
  3. Repita para Energia ativa (Soma, kcal) → ativas, Energia em repouso (Soma) → basal, Peso (Média, kg) → peso, Sono (Soma de "Dormindo", minutos) → sono, Treinos (Soma da duração, minutos) → treino.
    4. 
            
  4. Obter conteúdo da URL: URL  · Método POST · Cabeçalhos: apikey = , x-sync-token = seu token acima, Prefer = resolution=merge-duplicates, Content-Type = application/json.
    5. 
            
  5. Corpo da requisição (JSON): {"dia": <Data ontem formato aaaa-MM-dd>, "passos": passos, "kcal_ativas": ativas, "kcal_basal": basal, "peso": peso, "sono_min": sono, "treino_min": treino, "fonte": "atalho"}
    6. 
          

          
Se o Health não tiver algum tipo (peso, por exemplo), deixe o campo de fora. O servidor só aceita a linha se o token bater com a sua conta.
